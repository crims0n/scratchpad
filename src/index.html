      Workspace & Notes
      
            
      Use the folder button in the sidebar to create collapsible folders. Pinned notes stay at the very top as ordinary notes, while unpinned notes without a folder remain below the folders. Drag notes onto folders to move them, or right-click a folder to add a note, rename, reorder, or safely remove it. Deleting a folder from the sidebar returns its notes to the top level.
      
            
      Right-click a note and choose Delete Note to move it to trash. Click the trash icon at the bottom right and choose Restore to recover it. Restored notes return to their original folder, or the top level if it no longer exists. Right-click the trash icon (or focus it and press Shift+F10), choose Empty Trash…, and confirm to permanently remove recovery copies. Each local collection or workspace has its own trash, which survives restarts and never expires automatically.

      Editor Assistance
      
              
      Right-click in the editor and choose Insert for starter tables, task lists, code blocks, and links. Select text and type *, _, a backtick, or ~ to wrap it. Escape a Markdown trigger with a backslash when you want it to remain literal. Syntax highlighting and line numbers can be toggled under Scratchpad menu → Appearance.
      
            
      
          
      
        
      

        
        
      
          
      
            
      Connect an agent
      
            
      Turn Scratchpad menu → Agent access On, then open MCP Configuration to copy the command, argument, or generic JSON example into a local stdio MCP client. Configuration remains available while access is off. Keep Scratchpad open; MCP listening appears beside the save status while the server is enabled, even if no client is connected.
      
            
      Every time access starts, all five Read functions are enabled and all eight Write functions are disabled. Select individual permissions or Select all within a section. Changes apply immediately to all connected clients. Disabling access disconnects clients and resets permissions; reconnect your client after enabling access again.
      
            
      Agents see the collection currently open, including unsaved edits, and may send returned content to their model provider. Only you can restore notes or empty trash. Agents cannot read trashed note bodies or replace an entire note.
      
            
      Read functions
      
            
      
              
      
                
      list_folders
      
                
      Lists folders in sidebar order with their IDs, revisions, and assigned-note counts.
      
                
      Optional: limit (1–200), offset
      
              
      
              
      
                
      list_notes
      
                
      Lists note metadata and short previews in sidebar order. Use get_note for full content.
      
                
      Optional: folderId, limit (1–200), offset
      
              
      
              
      
                
      search_notes
      
                
      Searches note titles and Markdown content for literal, case-insensitive text.
      
                
      Required: query
      Optional: folderId, limit (1–200), offset
      
              
      
              
      
                
      get_note
      
                
      Reads one note by ID and returns a character-addressed chunk of its Markdown content plus its current revision.
      
                
      Required: id
      Optional: offset, limit (1–100,000)
      
              
      
              
      
                
      list_trash
      
                
      Lists deleted-note metadata. Agents cannot restore notes, read trashed content, or empty trash.
      
                
      Optional: limit (1–200), offset
      
              
      
            
      
            
      List and search results include nextOffset when another page is available. Continue from that offset until it is absent. Content offsets count Unicode characters, not bytes. When reading a note in chunks, restart if its revision changes.
      
            
      Write functions
      
            
      Read the current collectionId before writing. Edits and deletions also require the current revision from get_note or list_folders. After a timeout or failed save, retry the same request ID and identical arguments. Accepted edits that fail to save remain in the editor with Save failed; retrying saves the current state without applying the change again. Switching collections or restarting invalidates old collection IDs.
      
            
      
              
      
                
      create_note
      
                
      Creates and saves a note without changing your selection. Requires write access.
      
                
      Required: collectionId, requestId, title
      Optional: content, folderId
      
              
      
              
      
                
      create_folder
      
                
      Creates and saves a folder. Duplicate and reserved names are rejected. Requires write access.
      
                
      Required: collectionId, requestId, name. Read the collection ID first; reuse the same request ID and arguments when retrying.
      
              
      
              
      
                
      append_to_note
      
                
      Appends exact text, including your supplied newlines. Requires separate permission and the current revision from get_note. Conflicts require rereading. Failed saves remain visibly unsaved; retry the same request to save without appending again.
      
                
      Required: collectionId, requestId, noteId, expectedRevision, content
      
              
      
              
      
                
      rename_note
      
                
      Sets and locks a title without changing note content. Requires the current revision from get_note. Retry identical arguments after a save failure.
      
                
      Required: collectionId, requestId, noteId, expectedRevision, title
      
              
      
              
      
                
      move_note
      
                
      Moves a note to an existing folder or the top level, preserving content and pin state. Requires the current revision from get_note. Retry identical arguments after a save failure.
      
                
      Required: collectionId, requestId, noteId, expectedRevision, folderId (null for top level)
      
              
      
              
      
                
      rename_folder
      
                
      Renames a folder while preserving its ID and note assignments. Requires the current revision from list_folders. Duplicate and reserved names are rejected. Retry identical arguments after a save failure.
      
                
      Required: collectionId, requestId, folderId, expectedRevision, name
      
              
      
              
      
                
      delete_note
      
                
      Moves a note to persistent trash with revision checking. Retry identical arguments after a save failure. You can restore the note from the trash icon.
      
                
      Required: collectionId, requestId, noteId, expectedRevision from get_note
      
              
      
              
      
                
      delete_folder
      
                
      Deletes an empty folder with revision checking. Move all assigned notes first, including pinned notes.
      
                
      Required: collectionId, requestId, folderId, expectedRevision from list_folders

      About Scratchpad
      
        
      
        
      
      

      
      
        
      Scratchpad is an open-source, local-first Markdown editor for notes, drafts, and code snippets. It pairs a focused desktop writing experience with live preview, flexible organization, and Markdown-aware editing tools.
      
        
      Built for macOS, Windows, and Linux, Scratchpad works without an account, cloud service, analytics, or telemetry. Notes and recoverable trash stay on your device. Optional MCP access lets connected agents read and, with your selected permissions, change the current collection; your agent may send returned content to its model provider.
