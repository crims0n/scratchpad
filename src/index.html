    Which fields should I use?
    
          
    Choose a local or stdio server, enter the executable path as the command, and add --mcp-stdio as one argument. No URL, headers, bearer token, or environment variables are needed.
    
          
    The client launches Scratchpad in a mode with no window. Enable access before connecting. If you disable access or close Scratchpad, reconnect the client after enabling access again. If you move the app, copy the updated command.
    
        
    

        
    Connected agents can read the current collection, including unsaved edits, and may send note contents to their model provider.
    
      
    
    
    
  
    

  
  
    
    
    
      
    
        
    
          
          
          
        
    
        
      
    

      
    
        
        
    
          
    
            
    Workspace & Notes
    
            
    Use the folder button in the sidebar to create collapsible folders. Pinned notes stay at the very top as ordinary notes, while unpinned notes without a folder remain below the folders. Drag notes onto folders to move them, or right-click a folder to add a note, rename, reorder, or safely remove it. Deleting a folder returns its notes to the top level.

    Editor Assistance
    
              
    Right-click in the editor and choose Insert for starter tables, task lists, code blocks, and links. Select text and type *, _, a backtick, or ~ to wrap it. Escape a Markdown trigger with a backslash when you want it to remain literal. Syntax highlighting and line numbers can be toggled under Scratchpad menu → Appearance.
    
            
    
          
    
        
    

        
        
    
          
    
            
    Read-only agent tools
    
            
    These functions expose the collection currently open in Scratchpad, including unsaved edits. They cannot create, change, move, or delete notes.
    
            
    
              
    
                
    list_folders
    
                
    Lists folders in sidebar order with their IDs and assigned-note counts.
    
                
    Optional: limit (1–200), offset
    
              
    
              
    
                
    list_notes
    
                
    Lists note metadata and short previews in sidebar order. Use get_note for full content.
    
                
    Optional: folderId, limit (1–200), offset
    
              
    
              
    
                
    search_notes
    
                
    Searches note titles and Markdown content for literal, case-insensitive text.
    
                
    Required: query
    Optional: folderId, limit (1–200), offset
    
              
    
              
    
                
    get_note
    
                
    Reads one note by ID and returns a character-addressed chunk of its Markdown content.
    
                
    Required: id
    Optional: offset, limit (1–100,000)
    
              
    
            
    
            
    List and search results include nextOffset when another page is available. Continue from that offset until it is absent. Content offsets count Unicode characters, not bytes.

    About Scratchpad
    
        
    
        
      
    

      
    
        
    Scratchpad is an open-source, local-first Markdown editor for notes, drafts, and code snippets. It pairs a focused desktop writing experience with live preview, flexible organization, and Markdown-aware editing tools.
    
        
    Built for macOS, Windows, and Linux, Scratchpad works without an account, cloud service, analytics, or telemetry. Your notes remain on your device unless you choose to move or share them.
